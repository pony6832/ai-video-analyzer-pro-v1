# AI 影音分析專業版 V1 / V2 Handoff

這個 repo 是「【AI 影音分析專業版 V1】」的乾淨搬運包，保留原始碼、前端、打包腳本與交接文件。

## Quick Start

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd webapp
npm install
npm run build
cd ..
.\start_web.ps1
```
